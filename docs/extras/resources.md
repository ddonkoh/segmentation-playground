## Email Services

### Transactional Email

- **[Resend](https://resend.com/)** - Modern email API (recommended)
  - Simple API
  - Good developer experience
  - Reasonable pricing
  - React email support

- **[SendGrid](https://sendgrid.com/)** - Email delivery service
  - Enterprise features
  - High deliverability
  - Analytics dashboard
  - Free tier: 100 emails/day


- **[Postmark](https://postmarkapp.com/)** - Transactional email
  - High deliverability
  - Detailed analytics
  - Free tier: 100 emails/month

### Email Testing

- **[Mailtrap](https://mailtrap.io/)** - Email testing service
  - Catch emails in development
  - Email preview
  - Free tier available

- **[MailHog](https://github.com/mailhog/MailHog)** - Local email testing
  - Self-hosted
  - Great for development

### Hosting Platforms

- **[Vercel](https://vercel.com/)** - Recommended for Next.js (used in ShipSafe)
  - Zero-config deployment
  - Automatic HTTPS
  - Edge functions
