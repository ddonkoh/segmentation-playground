# UI Components

Reusable UI primitives for building interfaces.

## Components

- [Button](./button) - Primary button component
- [ButtonCheckout](./button-checkout) - Stripe checkout button
- [ButtonSignin](./button-signin) - Authentication button
- [ButtonGradient](./button-gradient) - Gradient button variant
- [Card](./card) - Container component
- [Input](./input) - Form input component
- [Badge](./badge) - Label/tag component
- [Modal](./modal) - Dialog component
- [Loader](./loader) - Loading spinner
- [Logo](./logo) - Logo component
- [BuiltWithShipSafe](./built-with-shipsafe) - Attribution badge
- [TestimonialsAvatars](./testimonials-avatars) - Social proof component

## Usage Pattern

All UI components follow consistent patterns:

1. TypeScript interfaces for props
2. DaisyUI/TailwindCSS styling
3. Responsive by default
4. Accessible markup
